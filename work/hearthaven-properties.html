01 / The challenge

Boutique agency.
Template first impression.

Hearthaven Properties is a boutique Ottawa real estate agency founded in 2014. It sells character homes, urban apartments, and investment properties across the Glebe, Westboro, and Hintonburg neighborhoods — and it has built its reputation on something the big chains can't replicate: knowing the streets, knowing the light, knowing what a house feels like on a Tuesday morning. The website, by contrast, looked like it had been built by a template service. Generic stock photography, an inconsistent property grid, agent bios buried three clicks deep, and a "Contact us" button that opened a mailto link. Nothing about it said boutique. Nothing about it said Ottawa. For a real estate agency, the website is the first showing. A prospective buyer or seller who lands on the site is quietly assessing the same things they'd assess at an open house — taste, care, trustworthiness, and whether the agent behind the screen actually knows what they're doing. Hearthaven's site was failing that assessment before anyone picked up the phone.

02 / The approach

Editorial warmth.
Neighborhood-first.

We built the direction around three decisions. First, the visual language is warm and editorial — deep slate teal, warm walnut, soft brass, Fraunces serif for headings paired with Inter for the interface. It reads like a well-designed print property guide, not like a real estate portal. Second, the neighborhoods are treated as content, not categories. The Glebe, Westboro, and Hintonburg each get their own dedicated section with photography, a short essay on the character of the area, and a filtered set of listings. That structure reinforces exactly what makes a boutique agency different from a national chain. Third, the agent team gets real space. Six agents with portraits, bios, specialties, and direct email links — because in real estate, people are the product. The listing grid, filter bar, and single-property page are all built to work properly in vanilla JavaScript — filtering by type, price, bedrooms, and neighborhood — because a real estate site with broken filters is a real estate site that doesn't work.

Warm editorial design system with neighborhood-led structure

Working listing filter with price, type, bedrooms, and neighborhood

Agent team as first-class content, not an afterthought

03 / The build

Every listing
warmly framed.

The build is a static site with a working listing filter, a property detail page with an image gallery, and a neighborhoods section that treats local knowledge as the agency's strongest differentiator. The testimonials slider, the journal strip, and the booking form are all built in vanilla JavaScript — no libraries, no framework. The contact form does client-side validation and shows a clear success message on submit, and the dark-mode toggle is consistent across every page. The result reads the way a boutique agency should: warm, considered, quietly confident, and clearly local. It doesn't try to compete with the national portals on scale. It competes on taste and trust — which is exactly where Hearthaven wins.

In real estate, taste is the first showing.
